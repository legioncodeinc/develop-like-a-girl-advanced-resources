# Worksheets

Copy the worksheet you need into your own project or complete the printed workbook. Preserve the project's existing document structure. Empty fields are questions to resolve, not permission to invent facts.

| Worksheet | Use it when |
| --- | --- |
| [Project brief](project-brief.md) | You need one place for the goal, audience, scope, and accepted decisions. |
| [Task handoff](task-handoff.md) | You are starting a bounded change or handing work to another session. |
| [Release checklist](release-checklist.md) | You are collecting evidence for review and an owner release decision. |

The [Project Brief Workbook](../downloads/project-workbook.pdf) combines all three for printing. The [Getting Started Guide](../downloads/getting-started.pdf) and [Command Card](../downloads/command-card.pdf) are companion references.
