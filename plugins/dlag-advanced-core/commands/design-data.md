# Design Data

Load `dlag-advanced-core:data-foundation` or read its [packaged Playbook](../skills/data-foundation/SKILL.md), procedure and worksheet directly. Use the [paired Specialist](../agents/data-foundation.md) only when available and delegation is authorized; otherwise perform direct use with the same limits.

Produce the smallest useful schema, operation matrix, indexes, WorkOS user mapping and explicit owner or organization predicates for every query. Neon authorization is server-side by default; do not assume automatic RLS or browser database access. Identify transaction-driver requirements and concurrent conflict handling. Save a local schema/migration draft or worksheet only within the requested scope, preserving existing files. Never apply a migration, install a client, access credentials, change a hosted database, commit, push or claim native isolation proof from source text. Read [edition boundaries](../references/edition-boundaries.md).
