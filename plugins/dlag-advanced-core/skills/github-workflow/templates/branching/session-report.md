# Reports

This folder collects past branching policy documents and advisory outputs produced by the authorized reviewer.

Each time the reviewer produces a branching policy document for a team, the output may be archived here as `YYYY-MM-DD-{repo-or-team-slug}-branching-policy.md`.

## Report format

Each report should include:
- The team context (size, product type, release cadence)
- The model recommendation and rationale
- The migration plan (if applicable)
- The feature flag verdict
- Any open questions routed to `the authorized repository-settings owner` or `the authorized CI owner`
