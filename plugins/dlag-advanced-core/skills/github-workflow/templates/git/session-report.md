# Reports

Use this report shape in chat for a scoped Git review. The caller saves it only when that separate action is authorized and write tools exist.

Each report is a dated markdown file: `YYYY-MM-DD-<topic>.md`

## Format

Each report should include:
- **Problem:** What the developer came in with
- **Diagnosis:** Root cause or situation
- **Solution:** Commands applied and outcome
- **Lessons:** Any edge cases or non-obvious findings worth noting

## Refresh

Keep actual past evidence only when the task authorizes a report artifact. Never claim a command was applied from a proposal or create automatic session memory. Retain the scope, artifact identity, dates and unresolved recovery limits.
