# Repository-health evidence notes

Keep declared metadata, effective configuration, actual execution and exact candidate proof separate. Read all eleven local guides for a full audit, or only the requested dimensions for a scoped review. The full model covers eight scored dimensions and one qualitative branch-policy narrative.

Protection/rulesets, owner enforcement, account security settings, fork/environment grants and runner/provider conditions need actual dated supplied evidence. Files alone cannot prove them. Commit-format statistics need the actual sample and accepted convention; missing bodies do not prove breaking-change/footer compliance. CODEOWNERS path matching needs correct GitHub semantics, active base branch and valid authorized owners; a naive abbreviated matcher cannot establish coverage.

Automation review traces event/filters, workflow and checkout revision, controllers of executable code/config/dependencies, workflow/job effective token grants, secret names only, environment protections, OIDC trust, artifact/cache origin and runner reuse. Never execute fetched artifacts to prove a concern. Required-check platform success or skips do not establish task execution; use exact candidate SHA, run/attempt, workflow revision, expected App and actual completed stages. Security Review owns vulnerability implications; the authorized CI owner owns architecture; the owner controls settings actions.

## Primary references and limits

[GitHub code-owner documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners) supplies location order, syntax, owner requirements and enforcement distinctions. [GitHub Actions secure use](https://docs.github.com/en/actions/reference/security/secure-use) supplies trust-boundary guidance. Product/version-specific settings and the actual repository policy still require supplied evidence.

The local guide includes the complete method without requiring an original-source archive, unfinished companion matcher or missing sample script. If a real coverage calculation, account/plan check or live run export is absent, report the gap. Do not manufacture source dates, scope, percentages or provider state.
