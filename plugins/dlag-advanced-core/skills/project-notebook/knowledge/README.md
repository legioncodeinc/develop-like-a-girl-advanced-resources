Project Notebook owns these local documents alongside its requirements and decision methods. Use the existing schema and the actual requested scope; a narrow explanation does not start a documentation fleet.

Read [document permissions](../references/library-boundaries.md). Existing accepted decisions explain intent; real source establishes implemented paths/symbols; runtime evidence establishes only what actually ran. Record conflicts and missing evidence. No live connector, code-entity extractor, external renderer, provider integration, package installation, publishing or sending is implied. Local Python/TypeScript fixtures are inert teaching inputs, not a selected backend or complete application. Their expected results are illustrative and NOT_RUN for this package.
