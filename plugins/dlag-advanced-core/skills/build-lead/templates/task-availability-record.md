## Eight independent evidence layers

| Layer | Exact safe evidence, identity and observation time | Status and limitation |
| --- | --- | --- |
| Source | Canonical owner, component kind/root, full required method and hash | Source only / missing |
| Package | Owner version, manifest, retained resource hashes and actual check result | Structural only / missing |
| Selected availability | Actual registered selection, checked prerequisites and supplied resolver result/refusal if applicable | Confirmed / UNKNOWN / refused; no native inference |
| Native discovery | Supported native observation, exact namespaced role/Playbook/command | Observed / UNKNOWN / UNEXECUTED |
| Execution | Actual bounded request, executor identity, result/failures and allowed effects | Observed / UNEXECUTED |
| Account/tool access | Actual scoped read/write/send/delete permission or denial, without credentials | Observed / UNKNOWN / DENIED |
| Action authority | Specific user instruction, target/payload/scope and exclusions | Present / absent; no tool-derived authority |
| Independent review | Reviewer/method, candidate-bound findings, fixes and rechecks | Observed / pending |
