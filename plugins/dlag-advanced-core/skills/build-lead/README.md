The [outcome index](references/outcome-index.json) can be read directly. The optional [Python shortlist helper](scripts/outcome-route.py) is for an authorized caller with execution tools; Build Lead cannot run it. Its [boundary tests](scripts/test_outcome_route.py) qualify lexical matching, input validation, unchanged evidence state and the Advanced 31-owner/14-command routing contract. They do not establish installed capability, user learning, implementation, provider readiness or release.

The [Advanced working guide](guides/advanced-workflow.md) and [Advanced procedure](guides/procedure.md) retain this edition's implementation and separate-builder boundaries. The routing JSON records the selected owners and public command namespaces; it is not evidence that those plugins are installed.
