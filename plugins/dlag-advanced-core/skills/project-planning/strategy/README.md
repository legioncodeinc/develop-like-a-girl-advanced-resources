# Product strategy guide map

Use [the strategy method](playbook.md) to interview the owner, retain evidence and confirmed choices, and save only the requested local documents. Every method below is packaged locally.

| Task | Guide |
| --- | --- |
| Run the interview | [Interview the owner](guides/interview-the-owner.md) |
| Inspect an existing product | [Start from an existing repository](guides/start-from-existing-repo.md) |
| Define problem, customer and job | [Sections 1 to 3](guides/define-problem-and-customer.md) |
| Establish positioning | [Five-part positioning](guides/position-the-product.md) |
| Choose strategic bets | [Bets and disproof signals](guides/choose-big-bets.md) |
| Define north star and inputs | [Metric method](guides/set-north-star.md) |
| Set appetite and exclusions | [Scope the first version](guides/scope-v1.md) |
| Identify the riskiest assumption | [Assumptions and smallest test](guides/find-riskiest-assumption.md) |
| Keep the decision history | [Record decisions](guides/record-decisions.md) |
| Assemble and revise the strategy | [Write and hand off](guides/write-and-hand-off.md) |

Use the [complete strategy template](references/templates/product-strategy.md), [nine-batch question bank](references/templates/interview-question-bank.md) and [decision-note template](references/templates/decision-note.md). Read [handoffs](references/handoffs.md) before dependent work. The [worked strategy](references/examples/worked-example.md) is fictional, including its customer stories, numbers, decisions and dates. It is not research or implementation evidence.

The [research explanation](references/research/distilled-product-strategy.md) retains the method findings, source-age limits and disagreements. The [read-only checker](scripts/check-strategy.py) validates document shape using Python's standard library. Shape, factual support, owner approval, implementation and live behavior require separate evidence.
