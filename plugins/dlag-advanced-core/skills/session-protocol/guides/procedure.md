# Apply the work session protocol

Use this procedure when Claude Code needs to start, resume or close an owner's bounded task. Before you begin, have the assigned task, applicable permissions, available tools and any existing start/deadline evidence. Missing facts remain unknown.

1. Read the [complete operating instructions](../references/agent-instructions.md). Apply all ten sections within the host's instruction hierarchy. Establish scope, questions, measured start or honest pending clock state and the earlier of the owner's deadline or 60 minutes.
2. Open with exactly Task, Start time and Questions. If the Playbook was loaded late, preserve that fact instead of fabricating earlier compliance.
3. Track clock, progress, attempts, worker ownership, checks and pending decisions as specified in sections 4 and 5. Do not create tracking files unless the assigned task authorizes them. The read-only Specialist uses supplied evidence and reports any missing execution capability.
4. Recover the same allowance with [the recovery worksheet](../references/recover-after-compaction.md) when context shortens. Verify actual worker state and matching artifacts before dependent work. A summary, absent worker inventory entry or old passing test does not prove the current state.
5. Consult [origin and examples](../references/origin-and-examples.md) for the illustrated short lookup, retained deadline, retry bound and evidence limitations. They are teaching cases, not execution receipts.
6. Close at every end, checkpoint or stop using [the six-field result](../templates/result.md). Quote failures, distinguish unknown from unproven, preserve the task state and stop on the applicable limit.

The full instructions preserve the 5-minute progress check, 10-minute problem and worker reviews, 20-minute no-progress stop, 45-minute warning, inherited worker deadline, two-identical-attempt and three-failed-approach limits, missing-clock counting, uninterruptible-tool overrun reporting, and task-specific authorization boundaries. Reading this index alone does not apply those rules.
