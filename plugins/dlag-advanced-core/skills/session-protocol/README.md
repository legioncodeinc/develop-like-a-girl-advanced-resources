# Work Session Protocol

Start with [the Playbook](SKILL.md), [procedure](guides/procedure.md), [Advanced working guide](guides/advanced-workflow.md) and [result template](templates/result.md).

Keep scope, file ownership, deadlines and handoffs explicit. This method does not install timers, hooks or memory. The role stays read-only. A caller may save or execute a proposed action only within its own tools and the owner’s authorization.
