# Optional observation helpers

Security Review is read-only and returns analysis in chat. These helpers are optional for a separately authorized caller with shell access. Loading this method does not authorize running them. No network check is required to use the worksheets.

`../../scripts/security_headers.py` accepts an explicitly authorized public HTTPS URL for one HEAD request, with a same-target GET fallback only for405/501. It does not follow redirects, use credentials/proxies, download response bodies or place orders. It pins a validated public DNS address for the connection and uses the original hostname for certificate verification. It emits redacted cookie names/attributes, minimized header observations and coarse TLS results to stdout. Location values expose only reference kind, safe HTTP origin and path/query/fragment presence. CSP output preserves recognized directive names and safe keyword/classification information; URI paths, userinfo, query values, fragments, nonce/hash values and opaque sources are redacted. Exact syntax/route comparison uses the explicitly approved redacted capture through Read/Grep, not opaque tokens in helper output. Treat each response as one observation, not complete site coverage. Public HEAD/GET requests still leave the machine and require task-specific authorization before execution.

`../../scripts/security_headers.py --capture SELECTED_REDACTED_JSON` analyzes one supplied capture offline. The schema is `{ "url": "https://example.invalid/", "status":200, "method":"HEAD", "headers":[["Content-Type","text/html; charset=utf-8"],["Set-Cookie","session=REDACTED; Secure; HttpOnly; SameSite=Lax"]] }`. Headers remain a list to preserve duplicates. Remove credential values before intake; do not use raw captures containing sessions or private URLs. The helper additionally redacts all cookie values and excludes credential/unknown headers from output. File intake refuses known environment/credential/human-note paths before opening, including .env*, .dev.vars*, private provider folders and notes directories. It does not blanket-exclude technical library/knowledge/private content. Explicit file selection is still required; a safe filename does not establish safe content.

The helper only identifies candidates; it does not score/severity-rank, prove cookie purpose, parse all CSP grammar, authenticate, prove CSP browser enforcement, or evaluate payment integrity. TLS details are available only for a real authorized collection and are explicitly coarse. Stdlib only; no dependency install. Syntax and pure synthetic checks do not prove network behavior. No collection was performed while authoring this method.
