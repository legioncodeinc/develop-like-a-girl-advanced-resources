# 00. Scope React and qualify version evidence

> Advanced scope: this React catalog applies only to the separate Payload CMS. Other frameworks are conditional comparisons; no React/JSX helper inspects Svelte. Advisory versions remain historical candidates until current supplied primary evidence confirms them.

Security Review is read-only. Use supplied sources and outputs; optional scanner commands are for a separately authorized caller with an existing Python 3.9+ runtime. If no helper ran, inspect the same scope/checks manually and record NOT RUN. Do not create a workspace, install dependencies or run the audited application from this role.

1. Pin the exact repository/candidate and owner-authorized include/exclude paths. Record dirty/untracked and unavailable artifacts. Read the manifest governing each path and its actual monorepo lockfile. Source scan limits do not silently expand the task.
2. Identify the separate Payload CMS React/react-dom/Next/Payload versions, custom components, SSR/RSC surfaces, editor session adapter and content/sanitizer libraries. Scope every helper invocation to that CMS path. React Router, Waku and alternate-framework detections are conditional comparison evidence only, never Advanced defaults. Use the local Payload/Next procedure for server boundaries and declare absent Next advisory coverage.
3. Record a stack table: path, resolved React, renderer, actual RSC runtime or none, router/mode, server entry, relevant libraries and deployment evidence. Dependencies/config/feature regexes are leads; a deployed-process trace is separate.
4. The optional `scripts/react_version_check.py` reads npm lockfiles (nested v1 and packages-map forms), pnpm packages/snapshots and yarn Classic/Berry. Its date-labelled table is only an offline 2026-09-30 snapshot. All output candidates need current primary advisory/version/feature/deployment confirmation before becoming present-day findings. A package.json range is not a resolved installed version. No matches cannot establish safety.
5. An authorized caller can run `python3 <local-method>/scripts/react_version_check.py --repo <repo> --paths <scoped-relative-paths> --out <fresh-external-path> --summary <fresh-external-summary> --start-id 1`. It refuses absolute/parent paths, escaping roots and outputs inside the target or already existing. Supplied summaries must retain date, actual lockfiles, parsed observations, feature evidence and every cap.
6. Hand-check unsupported Bun lockfiles, prereleases/canary/experimental builds, vendored copies, Git/tarball/local references and missing/oversized/unreadable files. Do not infer dependency maintenance from lockfile release age. Keep snapshot and current-advisory evidence separate. Review package identity/feature preconditions even when a resolved version matches a table row.
7. The optional `scripts/sink_scan.py --repo <repo> --paths <scoped-relative-paths> --out <fresh-external-path>` returns candidate path/line/check identities and bounded redacted excerpts. It does not read environment-file contents and does not establish any exploit. Missing paths, symlinks, file/count/size and per-check caps must remain visible. Rerun a capped check with explicit existing scope, e.g. `--checks RX-01 --max-per-check <bound>`, only through an authorized caller when needed.
8. Apply guide 01 to all React UI and its SSR half when SSR actually exists. Apply guide 02 only to actual RSC/Server Function surfaces, guide 03 to all client exposure, guide 04 to backing server decisions including forms/redirects even without login, and guide 06 to relevant packages/patterns. State the reason for every skipped surface.
9. Trace each candidate manually. Promote only with source/permission/sink evidence and current advisory facts where needed; otherwise record possible/Not confirmed with its exact missing fact. Script confidence is heuristic and cannot replace target evidence or lower a demonstrated impact.
10. Return resolved version/path/mode measures, lockfile presence, actual feature and deployment evidence, current-advisory verification status and all caps. Use the [full finding rules](../references/finding-rules.md), [table](../references/advisory-table.md) and [search patterns](../references/detection-patterns.md).
