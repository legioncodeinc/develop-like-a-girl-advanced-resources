# Ready Check resource map

Read [the Playbook](SKILL.md), follow [the complete procedure](guides/procedure.md), and return [the result](templates/result.md).

The sequence is Build Lead routing and actual candidate scope, Security and any complete re-evaluation, Quality and any complete re-evaluation, required dependency evidence, then the parent's direct repository review. Use available local [Security](../security-review/SKILL.md), [Quality](../quality-review/SKILL.md), [Dependency Review](../dependency-review/SKILL.md) and [GitHub Workflow](../github-workflow/SKILL.md) methods. Loading a method does not dispatch another reviewer or grant tools.

Keep the actual candidate, findings, changes and report locations bound together. Missing evidence stays missing. Supply an independent reviewer where the author would otherwise review their own work. This gate ends at owner review; external operations require their own task authorization.
