# Explanation template

Explain the supported outcome in plain English.

## How the pieces connect

Preserve actors, conditions, order, refusal, time limits, and status. Add a clearly labeled illustrative example only when it helps the question.

## Analogy and limits

## Words to know

## Sources and unknowns

Cite the supplied source by line or section. List unresolved facts and avoid claiming code execution.

## Check my explanation

For a requested teaching interaction, invite the reader to explain the key relationship. Otherwise omit this section; do not invent evidence of understanding.
