# Contracts

One CTR records one shared, observable boundary. The owner-authorized contract author drafts the terms and records the user's acceptance of the exact revision. The requirements author pins accepted revisions in each affected PRD under `## Contract dependencies` and keeps those links current as PRD folders move.

Use `CTR-<###>-<slug>.md` with the next unused number. Accepted terms stay immutable. Changed terms receive a new CTR number with links between the old and new records. Keep records here when PRDs move between lifecycle folders.

Draft text is not an accepted agreement. project foundation planning can prepare Draft records or pin existing Accepted revisions; its output does not supply approval. Legal agreements belong elsewhere.
