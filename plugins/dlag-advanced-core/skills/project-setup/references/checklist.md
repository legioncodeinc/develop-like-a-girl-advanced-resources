# Setup proposal check

- The project/root, selected edition and one outcome are explicit.
- Every proposed path was checked for existing material or marked inaccessible.
- Existing work is preserved and conflicts are visible.
- No home instructions, credentials or provider configuration were changed.
- The proposal fits the selected edition and only needed providers appear.
- Account statements have evidence types and environment boundaries.
- Commands and test scripts are marked proposed, declared or actually run.
- The first task has one observable result and a failure path.
- The answer claims an inspection/proposal, never a scaffold, deployment or completed account setup.
